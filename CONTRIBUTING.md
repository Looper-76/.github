# Contributing standards

- Work in scoped branches with PR review, named verification checks and explicit acceptance criteria.
- Keep each product's secrets, data and authorization boundaries independent.
- Do not commit credentials, customer datasets, employer-owned code, or employer-specific design assets without written rights and authorization.
- Do not treat an AI-generated assessment as sufficient proof of safety.
- Required security verification must fail **incomplete**, not pass, if the scanner or provenance is missing.
- Never allow AI-produced content to authorize cloud, GitHub, identity, or deployment actions by itself.
